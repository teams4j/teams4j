# Security Policy

## Reporting a security issue

Please report security issues privately through GitHub's private vulnerability reporting:
<https://github.com/teams4j/teams4j/security/advisories/new>

Do not use the public issue tracker for security issues.

Please allow up to 90 days to remediate a vulnerability before public disclosure.

## Supported versions

Only the latest release receives security fixes.

## Verifying artifacts

Every artifact on Maven Central is signed with the maintainer's GPG key. Releases are built and
signed on a maintainer's machine; no signing key or publishing token is stored in GitHub. See
[RELEASING.md](RELEASING.md) for the details.
